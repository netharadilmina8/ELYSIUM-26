## Motion system
The website includes lightweight, dependency-free cinematic motion:
- Hero entrance choreography on page load
- Scroll reveal animations using IntersectionObserver
- Scroll progress bar
- Subtle hero/background parallax while scrolling
- Floating exploration cards
- Timeline line reveal and row hover movement
- Button shimmer effects
- Premium card sheen/tilt interactions on desktop
- Soft cursor glow on pointer devices
- Reduced-motion accessibility support

No external JavaScript animation library is required.
